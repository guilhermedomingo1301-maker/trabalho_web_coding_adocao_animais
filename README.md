# 🐾 Patinhas Felizes - Plataforma de Adoção de Animais

Este é um projeto acadêmico e funcional desenvolvido para a disciplina de **Web Coding**, com o objetivo de conectar animais resgatados a novas famílias responsáveis e carinhosas.

---

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível.
- **CSS3**: Layout moderno e responsivo (Flexbox, CSS Grid, variáveis CSS, animações suaves).
- **JavaScript (ES6+)**: Manipulação do DOM, filtragem dinâmica em tempo real, modal de adoção e armazenamento local (`localStorage`).

---

## ✨ Funcionalidades Principais

- 🐶 **Catálogo Interativo de Pets**: Listagem de cães e gatos disponíveis com foto, idade, porte, sexo e personalidade.
- 🔍 **Filtros Dinâmicos**: Filtragem por espécie (Cão/Gato), porte (Pequeno, Médio, Grande) e busca por nome em tempo real.
- 📋 **Formulário de Adoção em Modal**: Formulário para manifestar interesse de adoção com validação simples e confirmação.
- ❤️ **Favoritos**: Possibilidade de curtir e salvar pets favoritos no navegador (`localStorage`).
- 📱 **Design Responsivo**: Adaptado para smartphones, tablets e desktops.
